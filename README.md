# TuWebEn3Días — V1

Portada experimental inspirada en la web actual de TuWebEn3Días. Está hecha con HTML, CSS y JavaScript vanilla, sin framework ni dependencias de ejecución.

## Vista local

Abrí index.html en un navegador o levantá un servidor estático desde esta carpeta.

## Experiencia

- Escena isométrica en SVG con un negocio conectado a IA, nube, Maps y leads.
- Animaciones de líneas, señales y aparición al desplazarse.
- Movimiento sutil con el puntero, desactivado cuando el sistema pide movimiento reducido.
- Selector de demos que abre ejemplos públicos en tuweben3dias.com. No solicita ni transmite datos personales.
- Los enlaces a suscripción y WhatsApp siguen apuntando a los canales actuales del sitio.

La portada incluye noindex, nofollow porque esta versión funciona como revisión y no debe competir en buscadores con la web principal.
